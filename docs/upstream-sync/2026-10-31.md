## Decisions needed

- [ ] **1. Reopening windows at launch.** Upstream (`e2b92218`): `window-state.ts` saves each window's project, position, size and maximized/fullscreen state (settings.json) and reopens them. Ours: `window-session.ts`/`window-session-state.ts` do the same (README 2026-10-25). Chose: ours stays wired; upstream's `window-state.ts` and its tests are kept in the tree but unused. Alternative: switch to upstream's and delete ours; or delete upstream's file. Recommendation: delete the unused upstream module on the next sync to avoid dead code.
- [ ] **2. Self-improve nudge.** Upstream rewrote the nudge as a "recognize lasting rules" guide that writes memory files directly. Ours routes through `propose_project_memory` with review. Chose: ours, plus upstream's recognition cues and one-off list. Alternative: upstream's text wholesale (bypasses the review flow). Recommendation: keep as is.
- [ ] **3. Process-tree stopping.** Upstream's `detached` + `killRuntimeProcessTree` (for its MCP availability check) overlap our `processGroup` tracking (kill on quit, descendants). Chose: ours, with upstream's names as aliases. Alternative: use upstream's simpler implementation. Recommendation: keep.
- [ ] **4. Per-project Claude account.** Upstream (`4d9fb68d`): each window runs on its project's account. Chose: upstream's, hidden when the backend is OMP like our other account rows.
