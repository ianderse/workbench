## Decisions needed

1. **Version hook.** Upstream versions the app from git history: `.husky/post-commit` amends `package.json` with a bumped version (`.github/scripts/sync-version.cjs`) and a GitHub workflow bumps the minor on merged PRs. Ours: `package.json` keeps the plain base version 1.0.0 (releases take the version from the tag). Chosen: kept ours; the hook files came in and `prepare: husky` installs it on `npm install`, so local commits will bump the version unless disabled. Alternatives: drop `prepare`/husky and the hook/workflow; or adopt the scheme. Recommend: remove the hook and workflow from this fork, since release versions come from tags. Check that the new workflow (if any under `.github/workflows`) does not push to `main` or point at proactive-agent.
2. **Agent window Session menu (OMP).** Upstream adds a Session menu (list/open sessions) built on Claude Code transcripts. Chosen: taken as is, Claude backend only; OMP windows only get the resume path above. Recommend: leave until OMP session listing is wanted.
