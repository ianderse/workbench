# Workbench

Workbench is a desktop app for Windows, macOS, and Linux that hands your coding tasks to the Claude Code CLI installed
on your machine. You describe what you want done; Claude Code triages the task, plans it when needed, implements it, and
validates the result with your project's checks and a fresh review, all inside an isolated git worktree so your main
branch stays untouched until you review and merge. Tasks move across a Kanban board as they progress, and the app adds
Claude Code agent windows, codebase chat, and pull request creation on top.

See [CLAUDE.md](CLAUDE.md) for architecture, packaging and contribution notes.
